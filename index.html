Rockchip cameras

The same Camemake modules, tested on a Luckfox Aura (RV1126B, CSI1). Camemake's European headquarters is in Berlare, Belgium. Install from ROCKCHIP_MIPI_CAMERAS. Other Rockchip boards keep these sensor settings and need their own overlay. Each card links to the sensor maker, the shop page, and that camera's folder.

GC4023

2.5MP, 2560×1440, 2-lane, link 351 MHz. Copy the gc4023 folder to the board, then sh build.sh and sh install.sh.
